# About

I'm a software developer in Kelowna, BC, with 20+ years of experience building and
modernizing production systems.

Since 2024 I've worked at Athena Industrial Services, building the software behind
railroad crossing diagnostics and industrial temperature monitoring: an ASP.NET web
platform, .NET MAUI mobile apps for Android and iOS, and the services that connect
them to field hardware over BLE and cellular.

Before that I spent four and a half years at WTFast working on core network
technology — Terraform on Google Cloud, build systems for the Windows client,
Prometheus monitoring, Go authentication servers, and porting services from gRPC
to ConnectRPC. Earlier still: consulting through Maplecake Software, ERP work, and
a decade of web development before that.

## What I care about

Refactoring and modernizing legacy code to a state where it earns its keep.
Continuous integration and developer workflows that don't get in the way. Writing
down how things work, so the next person doesn't have to reverse-engineer it.
